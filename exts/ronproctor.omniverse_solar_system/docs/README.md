# Omniverse Solar System Extension

Extension ID: `ronproctor.omniverse_solar_system`

This extension displays a J2000 SPICE/MPC orrery and animates asteroids through a
Warp-driven zero-copy Fabric deformable mesh. Version 2.12 adds an optional,
throttled diagnostics readout; uses one persistent Sun-centered oblique camera;
and defaults planet markers to X-Large. It preserves the generation-safe GPU
renderer and corrected 16K J2000 star background from v2.11.

Launch with Fabric Scene Delegate enabled and use Kit SDK 110.1.3 or newer.
